## Descripción

Se valida en entorno local el flujo de compra semanal asistida en la página **Smart Weekly Shop**, partiendo del acceso a la web y del inicio de sesión mediante el mecanismo simplificado de la POC.

Durante la prueba se comprueba que el usuario puede desmarcar la preferencia **Dieta equilibrada**, aplicar el filtro rápido **En oferta**, eliminar de la cesta recomendada el producto **Plátano de canarias igp (peso aproximado de la unidad 135...)** y retirar posteriormente el filtro para volver a visualizar la cesta completa.

Después, se valida que el usuario puede aceptar la cesta y añadir desde las sugerencias abiertas tras la aceptación el producto **Lomo supremo de bacalao desalado**.

A continuación, se comprueba el comportamiento del flujo de optimización por presupuesto: tras confirmar el pedido, el sistema permite ejecutar **Optimizar pedido** y recomienda quitar **Lomo supremo de bacalao desalado** porque se supera el límite de **30 euros**. La recomendación no se acepta; se cancela la optimización y se continúa hacia **Revisar y confirmar**.

En la pantalla de revisión se comprueba que aparece una indicación visual de presupuesto, representada como una línea naranja, que confirma que se ha superado el límite establecido. Finalmente, se confirma el pedido, se espera a que el flujo avance hasta **Entregado**, se continúa tras la entrega y se envía una valoración de **1 estrella**.

> **Nota para POC local**: este test está definido para ejecución sobre entorno local. No debe vincularse con pasarelas de pago reales ni generar pedidos reales salvo autorización expresa del equipo responsable.

## Preconditions

- Aplicación Smart Weekly Shop desplegada y accesible en entorno local.
- URL local disponible: [http://127.0.0.1:4200/anticipar]
- Usuario de prueba disponible para iniciar sesión.

- Compra sugerida disponible para el usuario de prueba.
- La preferencia **Dieta equilibrada** aparece marcada inicialmente o está disponible para desmarcarse.
- El filtro rápido **En oferta** está disponible.
- El producto **Plátano de canarias igp (peso aproximado de la unidad 135...)** aparece dentro de la cesta recomendada al aplicar el filtro **En oferta**.
- El producto **Lomo supremo de bacalao desalado** aparece disponible en las sugerencias que se muestran después de aceptar la cesta.
- El límite de presupuesto establecido para la compra es de **30 euros**.
- Al añadir **Lomo supremo de bacalao desalado**, el importe de la cesta supera el límite de **30 euros**.
- El flujo de optimización puede recomendar quitar **Lomo supremo de bacalao desalado** por superar el presupuesto.
- El flujo de pedido puede avanzar hasta el estado **Entregado**.
- Navegador con sesión limpia o ventana privada para evitar interferencias de ejecuciones anteriores.
