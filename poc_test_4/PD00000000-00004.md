### Descripción
 
Se valida en entorno local el flujo completo de compra semanal asistida en la página **Smart Weekly Shop**, reutilizando la misma estructura funcional que los tests de referencia y variando únicamente los productos utilizados durante el recorrido. 
Durante la prueba se comprueba que el usuario puede acceder a la web, iniciar sesión mediante el flujo simplificado de la POC, revisar una compra sugerida, eliminar un producto de la cesta propuesta, aceptar la cesta inicial y añadir más artículos posteriormente. 
Después, se valida la incorporación de productos adicionales de dos formas:
- Añadiendo manualmente **queso mozzarella rallado de vaca elaborado con leche pasteurizada**.
- Usando el chat con el asistente para buscar **fusilli** y añadir la primera opción propuesta. 
A continuación, se comprueba que el usuario puede ajustar el pedido, revisar y confirmar la compra, cambiar el método de pago a **PayPal**, confirmar el pedido y esperar a que el flujo avance hasta el estado **Entregado**. 
Finalmente, se valida que el usuario puede continuar tras la entrega, valorar la experiencia con **5 estrellas**, enviar la valoración y activar el recordatorio. Si aparece en el modal el texto **“Recordatorio Activado”**, el test se considera finalizado con éxito. 
**Nota para POC local**: este test está definido para ejecución sobre entorno local. No debe vincularse con pasarelas de pago reales ni generar pedidos reales salvo autorización expresa del equipo responsable.
### Preconditions
- Aplicación Smart Weekly Shop desplegada y accesible en entorno local.
- URL local disponible: [http://127.0.0.1:4200/]
- Usuario de prueba disponible para iniciar sesión.
- En la POC, usuario y contraseña se rellenan automáticamente al hacer click en los campos o en el flujo de login correspondiente.
- Compra sugerida disponible para el usuario de prueba.
- El producto **Plátano de Canarias IGP (peso aproximado de la unidad 135 g)** aparece dentro de la compra sugerida.
- El producto **queso mozzarella rallado de vaca elaborado con leche pasteurizada** está disponible para añadirse a la cesta.
- El asistente de chat está disponible y responde a la búsqueda **fusilli**.
- El flujo de pedido puede avanzar hasta el estado **Entregado**.
- Navegador con sesión limpia o ventana privada para evitar interferencias de sesiones anteriores.

- La primera opción propuesta por el asistente para **fusilli** se puede añadir correctamente a la cesta.
- El botón **Ajustar mi pedido** permite avanzar al ajuste del pedido.

- El método de pago puede cambiarse correctamente a **PayPal**.
- El botón **Confirmar mi pedido** confirma el pedido dentro del flujo de la POC.
- El flujo de compra avanza correctamente hasta el estado **Entregado**.
- El botón **Continuar** permite avanzar tras la entrega.
- La experiencia se puede valorar con **5 estrellas**.
- La valoración se envía correctamente.
- El recordatorio puede activarse correctamente.
- El modal de confirmación muestra el texto **“Recordatorio Activado”**.
- La aparición del texto **“Recordatorio Activado”** marca el test como finalizado con éxito.
