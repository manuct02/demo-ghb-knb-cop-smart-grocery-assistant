## Descripción

Se valida en entorno local el flujo completo de compra semanal asistida en la página **Smart Weekly Shop**.

Durante la prueba se comprueba que el usuario puede acceder a la web, iniciar sesión mediante el flujo simplificado de la POC, revisar una compra sugerida, eliminar un producto de la cesta propuesta, aceptar la cesta inicial y añadir más artículos posteriormente.

Después, se valida la incorporación de productos adicionales de dos formas:

- Añadiendo manualmente **espárragos verdes**.
- Usando el chat con el asistente para buscar **arroz** y añadir la primera opción propuesta.

A continuación, se comprueba que el usuario puede ajustar el pedido, revisar y confirmar la compra, cambiar el método de pago a **PayPal**, confirmar el pedido y esperar a que el flujo avance hasta el estado **Entregado**.

Finalmente, se valida que el usuario puede continuar tras la entrega, valorar la experiencia con **4 estrellas**, enviar la valoración y activar el recordatorio. Si aparece en el modal el texto **“Recordatorio Activado”**, el test se considera finalizado con éxito.

> **Nota para POC local**: este test está definido para ejecución sobre entorno local. No debe vincularse con pasarelas de pago reales ni generar pedidos reales salvo autorización expresa del equipo responsable.
