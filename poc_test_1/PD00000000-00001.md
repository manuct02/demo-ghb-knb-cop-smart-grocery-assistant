## Descripción
Se valida el flujo funcional básico de una aplicación local partiendo del login con el usuario de demo **Laura**. Tras autenticarse correctamente, la prueba comprueba que se puede aceptar la cesta predeterminada y continuar el recorrido completo por las distintas pantallas del proceso: **Ajustar**, **Confirmar**, **Entrega** y **Fideliza**.

El objetivo de esta prueba es reutilizar la misma estructura documental del test de referencia para facilitar la automatización y minimizar errores de verificación en el copiloto. La prueba finaliza al llegar a la pantalla **Fideliza**, sin continuar más allá de ese punto.

> **Nota funcional**: este test no necesita completar ninguna acción posterior a la llegada a **Fideliza**. El criterio de éxito es alcanzar esa última pantalla y detener la ejecución ahí.

## Preconditions
- Aplicación local levantada y accesible en `http://localhost:4200/`.
- Usuario demo disponible para iniciar sesión.
- En el copiloto se definirá el significado de **login como Laura**.
- La cesta predeterminada debe estar disponible para ser aceptada tras el login.
- Navegador con sesión limpia o ventana privada para evitar interferencias de ejecuciones anteriores.
